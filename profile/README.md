## Core LibreOffice Features

- **Writer, Calc, and Impress:** Open a text document, a spreadsheet, or a presentation you are allowed to edit.
- **Save a Named Copy:** The first save of a file you were sent should be a new name if the sender still needs the original.
- **Local Files:** The document lives where you save it. A cloud copy is a separate step you choose.
- **Export to PDF:** A PDF is a delivery file. Keep the editable document if you will change it again.

---

## About LibreOffice

LibreOffice is an office suite for documents you create or were asked to revise. A letter, a budget, or slides for a talk you are giving are ordinary work. It does not remove a password from a file you cannot open, and it does not make a template you found online into something you may republish as your own product.

Save early. An unsaved window is not a file. Use a folder you will find after a restart, not a temporary download path. If you are editing someone else's spreadsheet, save a copy first so a bad formula does not replace their numbers.

PDF is for sending a version that should look stable. If you still need to change the wording, keep the Writer or Calc file as well. Closing without saving is a real loss. The recovery prompt is not a promise.

## Getting Started with LibreOffice

Prerequisites: A folder for your documents and one file you need to write or revise.

1. **Open or Create:** If the file was sent to you, use Save As before the first change.
2. **Edit and Save:** Save to that folder with a name you will recognize.
3. **Reopen the File:** Confirm the change is really on disk.
4. **Export a PDF:** Only when you need a copy that is not the working file.

## Professional & Personal Use Cases

- **A Letter or a Report:** Write it, save it, and export a PDF for the recipient.
- **A Shared Spreadsheet:** Edit a copy, then send the copy back with a clear name.
- **Slides for a Talk You Are Giving:** Keep the Impress file so you can fix a slide later.
- **A Template You May Use:** Start from a file you have rights to, and save your version separately.
